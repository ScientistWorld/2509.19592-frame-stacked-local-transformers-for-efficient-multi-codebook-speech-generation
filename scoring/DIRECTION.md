# Direction

Develop learned generators that preserve joint codebook structure, temporal coherence, diversity and speaker conditioning while reducing sequential primary generation steps. Improvements to models, local decoding, information passed between steps, training schedules, regularization and sampling are in scope. Model scaling is allowed within the available compute, provided the model generalizes rather than reproducing training utterances.

The larger-weight 4x operating point studies the high-stacking regime where quality becomes difficult. The main remaining gap of the reference is utterance-level consistency: carrying persistent per-utterance residual structure across primary steps. A solution must improve the actual generated distribution and dependencies, rather than optimize agreement with reference token IDs or exploit reported metadata.

These are shortcuts: calling or copying a hidden reference sampler; hand-writing the data process, or repairing tokens with the evaluator's validity rule; copying or splicing examples; false compute declarations, including using a 2x model for the 4x row; modifying canonical data or fixed comparisons; and substituting scores. A learned alternative that produces a better distribution is a scientific improvement, even when its architecture differs from the reference. Generated tokens cannot reveal hand-written samplers, splicing below 12-frame granularity, or actual sequential computation, so a separate shortcut review checks those.
