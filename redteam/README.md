Audit cases live in one folder per method, including a `run.sh` that installs that method, runs the visible training evaluator and then the restored hidden test with no arguments in a new process. `audit.py` shares setup and restores the original tracked data, method, baseline, scoring and evaluator after every case. It does not modify evaluator code, metric implementations, or the Python runtime. The only copied trained model is the reference AR 4x model, used for the authorized reuse of trained outputs.

`reference/artifacts/` preserves original predictions for unchanged comparison rows. `reference/scores_test_original.json` is used only for post-run rank analysis; no shortcut uses it to generate outputs. The method implementations use visible data, generator, model and artifact fields only. The paper and inaccessible workspace documents are unused.

All names starting `shortcut_` are shortcuts, including ties and negative controls. `honest_sampling` samples only independent first codebooks from learned logits; dependent codebooks remain generated by the learned local transformer. `more_training` trains the unchanged AR 4x model for 10,000 rather than 5,000 steps. Reference seeds are 7, 17 and 27. `weaker_training` uses 100 steps; `weaker_no_local` removes the local transformer at the same stack factor and 5,000 steps.
